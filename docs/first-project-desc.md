# 需求
我现在希望你帮忙不依赖任何AI Agent框架，完全手搓实现一个用于文件内容分析的 AI Agent。 它帮我读取文件，并且让你帮忙分析出每段内容的核心内容，并用最言简意赅的文字罗列出来。

# 技术要求
1. 使用 golang 来实现。
2. Memory的实现这一版不要依赖具体的向量数据库实例(比如Qdrant，Milvus) 。可以用内存数据库来说。
3. Tools 要抽象好。因为未来版本可能增加其他tools。

# 特别说明
由于是第一版，我期望是一个轻量级的应用，但AI Agent核心东西不能少，比如LLM + Loop + Tools + Memory + Goal，或者说体现 ReAct。
